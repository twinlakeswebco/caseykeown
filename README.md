# Casey Keown

Personal landing page for Casey Keown, Evansville, Indiana owner of Casey’s Dugout.

## Preview

Serve this folder with any static server, for example `python3 -m http.server 8080`, then open http://localhost:8080.

## Deploy

No build step or runtime dependencies. Serve the repository root on GitHub Pages, Cloudflare Pages, or any static host. All asset paths are relative, so the page also works under `/caseykeown/`. No custom domain has been assumed.

Before connecting a final domain, set an absolute `og:image` URL and add a matching canonical URL. No personal email or phone has been supplied; the contact action opens Casey's personal Facebook profile.

## Content

Edit `index.html` for biography, press, and links; `styles.css` for design. `assets/casey-portrait.jpg` is the supplied photo by Brodie Curtsinger; `assets/casey-life.jpg` is the supplied Pizza Man artwork. Images remain attributed. Source links are in the page and SOURCES.md. Barlow Condensed is self-hosted under the SIL Open Font License (assets/OFL.txt).
